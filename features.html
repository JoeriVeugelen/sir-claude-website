Inside the kingdom

A tour of everything Sir Claude keeps watch over.

The Kingdom

Every project folder becomes a building on a 3D map, drawn in the style of Warcraft II. Building size reflects how active a project is; color reflects its status. A day/night cycle tracks real time, so a glance at the skyline tells you how your whole workload is doing.

Terminal & Session History

Click into any building to open a real terminal for that project, alongside a readable history of its Claude Code sessions — no digging through raw logs.

Spellbook

Save the commands and scheduled jobs you reach for again and again, per project, and run them with a click instead of retyping them.

Conjure

Say what you want in plain language and Conjure translates it into the right command for the right project — no need to remember exact syntax.

Offline Voice Control

Speech recognition and text-to-speech run fully offline via whisper.cpp and Kokoro TTS. Control your kingdom by voice without any audio leaving your machine.

Telegram Remote Control

Pair your kingdom with Telegram to check status and send commands to a project from your phone, from anywhere.

Proving Grounds

A built-in arena for pitting LLMs against each other head-to-head — useful when you want evidence, not vibes, for which model wins a given task.

Built with a Fastify server on 127.0.0.1 and an Angular interface, with three.js rendering the kingdom — vibe-coded entirely with Claude Code itself.
